# Vocabulary & Reading Web

Static student-facing pages for Vocabulary Foundation 1–2 and Reading Intensive 1–2.

This repository contains only browser assets. Submission files continue to be stored in the teacher-owned Google Drive and recorded in the existing Google Sheets.

## Retake-test numbering rule

- The answer sheet must display the same question number printed in the embedded Word/Google Docs test.
- Do not restart the visible numbering at 1 for each exercise unless the source test itself does so.
- Use that same source question number in the answer controls, missing-answer warning, wrong-answer list, and post-submission review.
- Treat each question's `globalNumber` or `number` field as the source of truth for the displayed number.
